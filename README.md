# AI-3dPortfolio

Cinematic, dark-themed portfolio for a generative AI engineer — text, image, and audio systems with live demos. Built with Astro, GSAP/ScrollTrigger, React Three Fiber, and deployed on Vercel.

## Stack
- Astro (framework)
- GSAP + ScrollTrigger + Lenis (scroll animation)
- React Three Fiber + drei (3D hero)
- Vercel (deploy)

## Getting started
```bash
npm install
npm run dev
```
